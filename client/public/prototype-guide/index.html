How to use this preview

A clickable prototype of the agentic migration redesign of the Konveyor user interface.

Open the prototype

What this is

This preview shows a proposed design for agentic migration in Konveyor: a configuration plane (models, agents, skills and migration plans) and an execution plane (plan runs across an application portfolio). It is a prototype for discussion and feedback, not a product. Behavior, names and screens can change.

Your data

All data is mock data. It lives only in your browser, nothing is sent to a server, and it resets every time you reload the page or open a shared link.

Anything you create, edit, start or approve stays while you click around in the same tab. Reload to start over.

The prototype switcher

A dark bar marked Prototype only sits at the top of every page. It is not part of the design; it lets you change who you are and what state the system is in:

Persona
Platform Engineer (Admin) configures models and providers, Enterprise Architect (Architect) designs plans and runs migrations across the portfolio, Hub Migrator (Migrator) runs migrations with read-only configuration.
Scenario
The state of the system, for example Partial configuration, Preflight blocked, Running, Action required, Failed or Completed.
Stage
Shown on plan run pages in run scenarios: the stage of the run that is active (running, waiting for approval or failed).
Reset Prototype
Returns to the default persona and scenario and opens the start page, the Application inventory.

The switcher keeps its state in the address, so any view can be shared as a link. The parameters are protoPersona (platformEngineer, enterpriseArchitect, hubMigrator), protoScenario (for example configured, running, actionRequired, failed, completed) and protoStage (a stage number, starting at 1).

Key screens

Each link opens the prototype in a specific persona and scenario.

  • Application inventory with a preflight blocker (Enterprise Architect): select applications and run a migration plan.
  • A plan run waiting for approval (Enterprise Architect): review the stage and approve it.
  • A running stage with live agent output (Enterprise Architect): logs and transcript update as the agent works.
  • An application's Migration tab after a completed run (Enterprise Architect): target branch, commits and the plan run.
  • Migration plans with configuration checks (Enterprise Architect): stages, agents, models and skills.
  • Agents and Skills (Enterprise Architect): reusable configuration and where it is used.
  • Models in Administration (Platform Engineer): verification status, the organization default and credential references.
  • Application inventory as a Hub Migrator during a running migration.

Good to know

  • Use a desktop browser window; the screens are designed for desktop widths.
  • Some upstream Konveyor pages are present but not part of this redesign. They run on the same mock data.
  • This page is always available from the How to use this preview link in the switcher.
